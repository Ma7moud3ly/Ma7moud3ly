### [Fast Compose](https://github.com/fast-compose)
**An instant runtime for Jetpack Compose. No compiler, no build, no waiting.**<br>
An interpreter that reads Compose code and calls the real Compose APIs, so your UI renders in milliseconds on Android, iOS, desktop and the web.

[🌐 Website](https://fast-compose.github.io) · [▶️ Playground](https://fast-compose.github.io/playground/) · [🎓 Learn Compose](https://fast-compose.github.io/learn/) · [✍️ Try it](https://fast-compose.github.io/try/)

</td>
</tr>
</table>
